# Security

ATLAS is a documentation and metadata repository of the Active Inference
Institute. It currently contains no executable code, so the attack surface is
limited to documentation content and repository metadata.

## Reporting a vulnerability

If you believe you have found a security issue in this repository:

- For issues that should not be publicly disclosed, use GitHub's private
  vulnerability reporting for the repository at
  <https://github.com/ActiveInferenceInstitute/ATLAS/security/advisories>
  (enabled on this repository), or contact the repository stewards through
  the Active Inference Institute's public channels.
- For non-sensitive issues, open a regular
  [issue](https://github.com/ActiveInferenceInstitute/ATLAS/issues).

Please do not include credentials or other secrets in reports.
