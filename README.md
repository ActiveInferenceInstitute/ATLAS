# ATLAS

Repository of the Active Inference Institute. The Institute's public
[Open Source Map](https://activeinference.institute/knowledge/) classifies ATLAS
as a *project materials repository* within the *open-source projects* family.

This repository currently holds the InstituteOS metadata sidecar, the license,
and documentation scaffolding. No code or project content has been published
yet; see [TO-DO.md](TO-DO.md) for scoped work and open items.
